# Portfolio – Geospatial Developer & Analyst

A responsive portfolio site for geospatial development work: projects, client work, and experience.

## Tech Stack

- React 19, Vite, React Router
- React Icons, React Globe.gl (3D globe)

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build & Deploy

```bash
npm run build
```

Output is in `dist/`. Deploy that folder to Netlify, Vercel, GitHub Pages, or any static host (build: `npm run build`, publish: `dist`).

## Structure

- `public/` – static assets (images, resume)
- `src/components/` – React components
- `src/data/` – projects, experience, contact
- `src/pages/` – page components
- `src/styles/` – CSS and themes
